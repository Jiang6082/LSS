# LSS — Late-Summer Internship Scanner

US internships at well-known firms in software engineering, product management, data/analytics and finance/investment that can run **mid/late July → September 30, 2027**. Sister project of [QJS](https://github.com/Jiang6082/QJS), [PTS](https://github.com/Jiang6082/PTS) and [ECS](https://github.com/Jiang6082/ECS).

_The first scan is running in GitHub Actions; this README is replaced by the live dashboard when it finishes._

```bash
npm run scan       # full scan (community lists + official ATS boards)
npm run scan:fast  # community lists only
npm test           # offline self-test
```
